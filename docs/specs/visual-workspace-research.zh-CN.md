# 可视化配置工作台与恢复时间线

2026-09-05。范围：harness-switch 的功能发现、模型配置关系、首次使用及全局恢复体验。以下区分公开产品证据与本项目设计判断；没有把文档调研当作竞品实机测试。

## 调研结论

| 参考 | 可核实的设计机制 | 本项目采用的方向 |
| --- | --- | --- |
| [CC Switch](https://github.com/farion1231/cc-switch) | 预设、导入、托盘快速切换；官方截图突出工具和当前使用的供应商 | 从用户正在用的工具进入；把当前状态、切换入口放在一起，减少为一次切换创建对象的负担 |
| [Cherry Studio](https://github.com/CherryHQ/cherry-studio-docs/blob/main/pre-basic/providers/quick-reference.md) | 按供应商找到入口，填写密钥后获取模型列表 | 沿用供应商凭据与目录，收藏应在模型所在位置即可触达，而非要求用户先理解收藏的数据结构 |
| [n8n 工作流历史](https://github.com/n8n-io/n8n-docs/blob/main/docs/build/manage-workflows/view-change-history.md) | 选择版本时预览对应画布；区分工作流版本与执行记录；恢复前保留最新版本 | 选中时间点即预览当时状态；操作历史与可恢复点明确区分；恢复不等于重放操作 |
| [Apple Time Machine](https://support.apple.com/zh-cn/guide/mac-help/mh11422/mac) | 时间轴定位、前后浏览、选中备份高亮、查看内容后恢复 | 时间刻度、分层快照、当前/目标对照，让恢复对象可感知；保留单独确认步骤 |
| [SAO Utils](https://store.steampowered.com/app/786520/SAO_Utils_Beta/) | 开发者公开截图中的半透明空间面板与选中高亮，属于 SAO 风格桌面工具，并非动画官方产品界面 | 借鉴层次、细线与短暂聚焦动效，不复制角色面板、属性条或无意义扫描装饰 |

## 产品判断

当前的问题是概念与入口分散：用户需要先理解收藏、渠道、配置档案和激活，再拼出一次使用动作。卡片美化和增加说明不能独立解决这个问题。

目标是让用户在一个工作区回答三个问题：我现在用什么；这个模型能配置到哪里；出问题能回到哪一个时刻。

### 入口与第一次使用

- 将“模型工作台”“工具配置”“恢复时间线”作为稳定的一级导航，避免通过互相变名的按钮切换页面。
- 工作台顶部提供“从现有配置开始”和“连接供应商”两个真实起点。已有配置用户默认看到可复用的内容；空状态给出完整关系示意，示例须标为示例。
- 常用模型显示正在使用/已保存未启用/待同步/缺失渠道，主动作是“用于工具”。编辑、删除、解除关联降为次要动作。
- 在工具的配置位置提供收藏入口，减少往返独立页面。

### 配置关系可视化

- 固定三列“供应商 → 模型 → 工具”，由真实数据自动布局；默认不要求拖拽、画线或新建流程。
- 点击模型，高亮相应渠道及兼容工具；选工具后预览将改变的连接和原生文件，再明确确认保存或切换。
- 连接表示配置来源和写入关系，不能让用户误以为请求流量经过本服务，也不能用持续流动粒子伪装网络活动。
- 实线表示已建立关系；待变更使用虚线与文字标签；不兼容和缺失来源必须说明原因。颜色不能作为唯一信息。
- 多渠道先使用明确的现有选择；存在歧义才询问，不能静默切换供应商或凭据。
- 图形旁保留可键盘访问的列表/详情，窄屏转为顺序布局；无需缩放或拖动画布才能完成核心操作。

### 恢复时间线

- 全局入口常驻。以时间点、操作名称和工具组织记录，突出当前状态和所选恢复点。
- 选中时间点后，快照通过轻微纵深切换进入焦点；同时展示文件影响的真实预览，而非只有装饰缩略图。
- 旧备份没有操作名称则显示明确的旧记录说明，不能推测历史操作。
- 选择时间点只读，确认按钮明确写“全局恢复到此时”；删除、覆盖、还原缺失文件分开说明，沿用状态指纹防过时确认。
- 成功后展示结果与恢复前自动生成的恢复点入口。不能把全局回退叫作“仅撤销本次”。

### 视觉与动效

- 保留现有品牌紫色、IBM Plex 字体、圆角尺度与工具图标，扩展浅色/深色的同一套材质语言。
- 未来感来自有含义的层次：柔和表面光、细描边、聚焦节点、分层快照；正文保持高对比，不用全屏霓虹和闪烁。
- 选中关系高亮约 160–220ms，面板过渡约 240–320ms，时间快照约 300–420ms。减少动态效果偏好下取消位移/纵深，保留即时状态变化。
- 等待仅显示真实加载状态；成功动效必须由服务器成功结果触发，不用动画提前宣布完成。

## 验收标准

1. 首次进入能看到功能目的和起点；不阅读文档也知道下一步。
2. 已有一个供应商/模型时，无需再次选择协议、凭据和重复命名。
3. 选中模型即能解释它与渠道、工具之间的关系；切换与仅保存后果不同且清楚。
4. 恢复前能识别目标时刻、操作背景和实际影响，且不会因选时间点直接写入。
5. 键盘、窄屏、长名称、空状态、缺失渠道、部分失败和减少动态效果均能完成操作。
6. 设计与真实业务数据相连，保留事务、备份、脱敏和过时确认保护；测试及实机验证不修改用户日常配置。

## 已选择的组合与实现边界

用户选择结合三个方向：工作台以工具为起点，收藏页展示供应商、模型与工具关系，恢复页使用时间线和分层快照。三个页面共用常驻导航、现有明暗主题与组件。合并出图请求因图片服务连接失败未返回，实际实现以用户已认可的三张独立图为参照。

- 工作台使用真实收藏、渠道投影和工具激活信息。唯一可用渠道或已关联的渠道直接复用；多个渠道没有明确选择时阻止预览，避免隐式改变凭据来源。预览后仍需明确确认写入。
- 从当前工具配置收藏时预填来源和名称；需要提取凭据时保留明确同意。原有详细配置、迁移、凭据库、诊断入口继续可用。
- 收藏页可筛选模型、切换渠道并点击目标工具配置；编辑、解除关联与删除收在详情中。
- 时间线选择只读，展示恢复会覆盖、创建、删除的实际文件。备份没有结构化历史模型摘要，因此没有虚构旧模型拓扑或复制示例模型名称。手动恢复点及自动恢复点仍按原有加密与保留策略管理。
- 时间线的旧请求不会覆盖新选择，切换预览在离开页面后不会重新出现。恢复按钮只使用当前选中恢复点的有效状态指纹。
- 本轮未改变服务器的恢复事务、脱敏和备份范围。桌面较短窗口中，时间点与文件影响各自滚动；减少动态效果偏好下关闭新增位移与纵深动画。

实现和验证结果以项目根目录的 `design-qa.md` 及模型收藏实施记录为准。
