SERVER-SIDE CONTROL PLANE

harness-switch

SSH / HEADLESS

把 API 路由切换变成一个动作。

配置档案按 harness 独立管理。激活后会更新相应配置，并生成可在 SSH shell 中 source 的环境文件。

安全提示API key 仅在服务器本地加密保存，列表和页面不会回显明文。

Shell 使用方式

激活后，在运行 harness 的同一个 shell 执行：

source ~/.harness-switch/env.sh

也可以直接使用下面的服务器数据目录路径。Claude Code 与 Kimi Code 会额外写入各自的原生配置文件；pi、Codex、zcode 使用统一环境文件，避免覆盖你现有的复杂配置。

设计取舍

Web 页面改变的是服务器主机上的配置，不会改变浏览器本机环境；父 shell 需要 source 环境文件才能获取新变量。
